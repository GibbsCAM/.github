## Four Beats

1. **Name the program.** Give the GibbsCAM session a short title before you edit mill or lathe paths.
2. **Pin the live paths.** Keep current CNC programming on the GibbsCAM board and leave unused solids aside.
3. **Check the verification.** Read the GibbsCAM summary of toolpath verification before you treat a cut as final.
4. **Close the loop.** Note which paths are ready so the next GibbsCAM visit does not start by hunting the first cut check.

## First Questions

**Does GibbsCAM replace the machine table?**  
No. GibbsCAM sits beside the solid model and the shop traveler you already use.

**Can two machinists share one computer?**  
Yes. Each person keeps a separate GibbsCAM profile.

**Will GibbsCAM stay workable on an older office laptop?**  
Yes. GibbsCAM is meant to stay light during a normal first cut check.

**What should a new user try first?**  
One small GibbsCAM mill path today, then the same toolpath verification again tomorrow.

## Field Note

GibbsCAM is easier to trust when the program stays smaller than the solid it came from. A named session shows which cut is active, the pins show which mill and lathe paths you will verify today, and the closing note tells the next person which CNC programming passed the first cut check. That record is short on purpose: not a copy of every tool, only the path back to the program that is still open.

The same loop fits a student turning job, a client mill fixture, or a computer shared by two machinists. Open the last GibbsCAM session, confirm one verification, and leave the first cut easier to find than you found it. Travelers stay where they are. GibbsCAM only holds the mill and lathe paths, the summary, and the handoff.

## One Real Pass

Pick a solid that already has a name: a turned shaft, a milled plate, or a short boss. Open it in GibbsCAM, keep only those mill and lathe paths on the board, and read one verified path you can point to. A pass is done when that path is tied to toolpath verification and the unused solids are no longer in the way. GibbsCAM does not need a full rebuild of the part before it is useful.

If the pass feels crowded, the program is too wide. Drop anything that belongs to a different machine and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first tool to the last cut, with the summary still matching the CNC programming on the board.
